## 🎯 Objetivos da Disciplina

- ✅ Aplicar um processo de desenvolvimento de software com ênfase na **definição e elicitação de requisitos**.
- ✅ Iniciar o **Trabalho de Conclusão de Curso (TCC)**.

---

## 📚 Plano de Ensino

### Parte 1 – Revisão e Fundamentos
- Revisão de Conceitos: Processo de Software, Engenharia de Software, RUP e Scrum.
- Requisitos de Usuário x Requisitos de Sistema.
- Requisitos Funcionais e Não Funcionais.
- Elicitação, Especificação e Validação de Requisitos.
- Proposta do Projeto de Graduação.

### Parte 2 – Modelagem e Documentação
- User Stories e Casos de Uso.
- Casos de Uso Expandidos (descrição detalhada).
- UML – Diagrama de Classes:
  - Notação, Tipos de Associação, Generalização, Dependências.
- Diagrama de Classes – Visão Conceitual.
- Prototipação (Figma ou similar).

### Parte 3 – Artefatos e Entregas (para ES3)
Os seguintes documentos devem ser gerados e disponibilizados via **GitHub**:

- [ ] Proposta do Projeto (template ES2N-Proposta)
- [ ] Pesquisa/Questionário (template ES2N-AnexoPesquisa)
- [ ] Requisitos Funcionais (template ES2N-Requisitos Funcionais)
- [ ] Requisitos Não Funcionais (template ES2N-Requisitos Não Funcionais)
- [ ] Diagrama de Caso de Uso (template ES2N-DiagramaCasoUso)
- [ ] Descrição de Caso de Uso (template ES2N-DescricaoCasoUso)
- [ ] Diagrama de Classes (template ES2N-DiagramaClasses)
- [ ] Protótipo da aplicação (Figma)
- [ ] Model Canvas (se for projeto de empreendedorismo)
