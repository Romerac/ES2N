Este repositório contém os materiais, atividades e projetos desenvolvidos na disciplina de **Engenharia de Software 2**, ministrada pela Profª Mª Denilce Veloso, cursada na **FATEC Sorocaba**.

Durante a disciplina, são abordados os fundamentos da engenharia de software com ênfase na definição e elicitação de requisitos, além do início do Trabalho de Conclusão de Curso (TCC). A disciplina também integra atividades de extensão, promovendo a interação com a comunidade externa.

Este repositório serve como registro acadêmico das atividades realizadas ao longo do semestre e como material de estudo e consulta futura dos conceitos de engenharia de software.

---

## 📚 Objetivos da Disciplina

A disciplina tem como principais objetivos:

- Aplicar um processo de desenvolvimento de software, com ênfase na definição e elicitação de requisitos.
- Iniciar o Trabalho de Conclusão de Curso (TCC).
- Desenvolver projetos integradores com impacto social, atendendo a comunidade externa (empresas, ONGs, entidades assistenciais, etc.).

---

## 📖 Plano de Ensino

O conteúdo programático está organizado da seguinte forma:

1. **Revisão de Conceitos**: Processo de Software, Engenharia de Software, RUP e Scrum.
2. **Requisitos de Software**:
   - Requisitos de Usuário e Requisitos de Sistema.
   - Requisitos Funcionais e Não Funcionais.
   - Elicitação, Especificação e Validação de Requisitos.
3. **Modelagem com UML**:
   - User Stories e Casos de Uso.
   - Casos de Uso Expandidos (descrição detalhada).
   - Diagrama de Classes: notação, associações, generalização, dependências.
   - Diagrama de Classes - Visão Conceitual.
4. **Prototipação**: Uso de ferramentas como Figma para prototipagem de interfaces.
5. **Projeto Integrador**: Desenvolvimento de um projeto real para a comunidade, com entrega dos seguintes artefatos:
   - Proposta do Projeto
   - Pesquisa/Questionário
   - Requisitos Funcionais e Não Funcionais
   - Diagrama de Caso de Uso
   - Descrição de Caso de Uso
   - Diagrama de Classes
   - Protótipo (Figma)
   - Model Canvas (opcional)

## 📋 Critérios de Avaliação

A avaliação é composta por:

- **AV1 (20%)**: Avaliação teórica.
- **PJ1 (60%)**: Projeto integrador.
- **AT1 (20%)**: Média das atividades extras.

**Recuperação**:  
Se a média não for atingida, a média final será calculada como:  
`(Média anterior * 2 + Média reavaliação * 1) / 3`, devendo ser ≥ 6,0.

> ⚠️ **Atenção**: O projeto integrador é obrigatório para aprovação, pois faz parte da curricularização da extensão.

## 🧠 Atividade 1 - Mapa Mental

Como primeira atividade, os alunos devem criar um **Mapa Mental** sobre o tema **"Engenharia de Software"**, com base no vídeo indicado em aula.

### Diretrizes para o Mapa Mental:

1. **Ideia Central**: "ENGENHARIA DE SOFTWARE".
2. **Ramificações**: Conexões entre a ideia central e os subtemas (processos, modelos, requisitos, UML, etc.).
3. **Palavras-Chave e Imagens**: Utilize palavras e imagens que ativem a memória e facilitem a associação.
4. **Cores**: Use cores para destacar diferentes áreas e melhorar a compreensão visual.

### Ferramentas Sugeridas:

- [Xmind](https://xmind.app/) (gratuito para até 3 mapas por mês).
- Papel e caneta (fotografe ou digitalize o resultado).

### Entrega:

O arquivo do mapa mental deve ser enviado para o repositório GitHub do aluno, na pasta:

```
https://github.com/SEUUSUARIO/ES2N/Atividade1
```

## 🧩 Questões ENADE Comentadas

### Questão 1 (ENADE 2021)

> **Modelos de processo**: cascata e desenvolvimento incremental.

**Análise**:

- O modelo em cascata não prevê validação pelo cliente em todas as fases.
- No desenvolvimento incremental, os incrementos permitem validar a entrega e atender às necessidades do cliente.

**Resposta correta**: A) As asserções I e II são proposições verdadeiras, e a II é uma justificativa correta da I.

---

### Questão 2 (ENADE 2021)

> Gerenciamento de projeto com problemas de comunicação, escopo, qualidade e atrasos.

**Resposta correta**: e) Partes interessadas.

---

### Questão 3 (ENADE 2017)

> Modelos de processo: incremental, espiral e cascata.

**Análise**:

- I. Correta: especificação, desenvolvimento e validação são atividades do modelo incremental.
- II. Incorreta: no modelo espiral, a análise de risco não é atribuída especificamente à fase de modelagem.
- III. Correta: o modelo cascata é sequencial e sistemático.

**Resposta correta**: d) I e III, apenas.
